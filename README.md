# Customer Sales & Revenue Analysis

## Project Overview

This project analyses customer sales data using Microsoft Excel to identify revenue trends, regional performance, and top-performing products.

The project was created to demonstrate practical data analysis skills including data organisation, KPI calculation, PivotTables, data visualisation, and business insight generation.

## Tools Used

- Microsoft Excel
- PivotTables
- Charts & Data Visualisation
- KPI Analysis

## Key Performance Indicators

| KPI | Result |
|---|---:|
| Total Revenue | £38,174.02 |
| Total Orders | 200 |
| Total Units Sold | 598 |
| Average Order Value | £190.87 |

## Key Insights

- Birmingham generated the highest regional revenue, contributing approximately 23% of total revenue.
- Smart Watch was the highest-revenue product and the top-performing product in the dataset.
- The analysis provides a comparison of revenue performance across five regions.
- Product-level analysis highlights which products contributed most to overall revenue.

## Project Structure

The Excel workbook contains:

- **Sales_Data** – Original sales dataset
- **Summary** – KPI dashboard and key insights
- **Revenue by Region** – Regional revenue analysis
- **Revenue by Product** – Product revenue analysis

## Business Objective

The objective of this analysis is to help a business understand sales performance and identify high-performing regions and products that could support future sales and marketing decisions.

## Outcome

This project demonstrates how Excel can be used to transform raw sales data into clear, actionable business insights through KPI analysis, PivotTables, and visual dashboards.
